## What this is

Init of a repo aggregating ~5 years of working with Mapbox. Filling it with maps and components that have been useful to us and might be useful to other people too.

## Setup

Components need a Mapbox token. [Log in to Mapbox](https://www.mapbox.com) and grab one — the free tier is enough.

```bash
NEXT_PUBLIC_MAPBOX_TOKEN=pk.xxx
```
